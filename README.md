# CHE629 Course Project: Reproducing and Extending scBERT

Reproduction of **scBERT** (Yang et al., *Nature Machine Intelligence* 4, 852–866, 2022), a Performer-based
foundation model for cell-type annotation of single-cell RNA-seq data, using the authors' released pretrained
weights, plus two benchmark models and three extensions.

## Notebooks

| Notebook | What it does | Runtime |
|---|---|---|
| `scBERT_component2_reproduction.ipynb` | Downloads data and the pretrained checkpoint, preprocesses Zheng68K, Baron and two synthetic datasets, fine-tunes scBERT, reports test metrics | L4 GPU (~6 h from scratch) |
| `CHE629_component3_benchmarks.ipynb` | Logistic regression and MLP on the identical splits; accuracy / precision / recall / F1, per-class F1, confusion matrices | CPU (minutes) |
| `CHE629_component4_novelty.ipynb` | (A) scBERT-Lite, 2,000 HVG input; (B) attention-pooling head; (C) binning ablation | L4 GPU (~2 h from scratch) |
| `scBERT_results_and_demo.ipynb` | **Start here.** Part A shows every table and figure from the saved results; Part B reloads the saved fine-tuned weights and re-scores the test cells live | L4 GPU, ~8 min |

All expensive cells skip work that is already saved, so re-running a notebook against the existing Google Drive
folder only re-displays results.

## Quick start (all results in ~8 minutes)

1. Get access to the shared Google Drive folder `scBERT_run` (ask the author), then in Google Drive:
   *Shared with me → right-click `scBERT_run` → Organize → Add shortcut → My Drive* (keep the name `scBERT_run`).
2. Open `scBERT_results_and_demo.ipynb` in Google Colab, choose *Runtime → Change runtime type → L4 GPU*.
3. *Runtime → Run all*. Part A prints all tables and figures; Part B re-predicts the saved test cells and prints
   how many predictions are identical to those saved during training (100% on an L4).

## Data and weights

- scBERT code and pretrained checkpoint: https://github.com/TencentAILabHealthcare/scBERT
- Zheng68K PBMC (10x Genomics, fresh 68k PBMCs donor A): https://www.10xgenomics.com/datasets/fresh-68-k-pbm-cs-donor-a-1-standard-1-1-0 and labels from https://github.com/10XGenomics/single-cell-3prime-paper
- Baron human pancreas (GEO GSE84133): https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE84133
- Synthetic datasets: generated by `prep_data.py synthetic` (negative-binomial counts with planted marker genes)
